# Shukatsu OS 公开展示版

这是一个可以放在 GitHub 上的独立演示项目。公司、邮件、日期、事件均为重新编写的虚构样本，不包含个人经历、申请记录、真实邮件、账户信息或正式数据库。

## 怎么看

从[在线操作指南](https://yaenyanyako.github.io/shukatsu-os-showcase/#guide)体验。若看本地副本，在项目文件夹运行 `python3 -m http.server 8876 --bind 127.0.0.1`，再用独立浏览器打开 `http://127.0.0.1:8876/`；嵌入式预览可能拦截本地文件。无需依赖、账号或API key。

1. 点击 **12 件のサンプルを仕分ける**：查看按公司整理后的通知与下一步。
2. 点击 Mori Systems 的 **通知の根拠を見る**：查看为什么取消期限不等于报名期限。
3. 点击 **日程変更を追加**：原有日程原地更新，冲突消失。
4. 再次运行：查看重复通知被跳过，待办与日程不会重复创建。
5. 打开“会社・プロジェクト”→ Kumo Labs → AI 体验会，在项目页保存或推进，观察待办变化。

所有操作只保存在当前浏览器中。右上角可以重置；浏览器不允许保存时，会显示临时模式。演示日期固定为2030年5月，不代表现实日程。

- **完整走查**：导航里的操作指南串联通知、资料、研究、ES、阶段、核对及Calendar，说明每个按钮实际做什么。

所有例子重新编写，不包含正在选考的真实公司、岗位、进度、私人邮件或文书，也不展示私人台账数量。[本次变更说明](CHANGELOG.md)。

## 保留的公司与项目准备区

- **公司 → 项目**：4家虚构公司、7个项目，同公司本选考和实习的截止、邮件、ES 分开保存。
- **ES**：可编辑草稿、字数检查、版本保存，以及“具体性／深挖／表达”的简易诊断。
- **研究和蒸馏**：七维度企业研究、行业比较，演示从 OpenWork、BizCampus、外资就活、ONE CAREER 等来源收集资料并保存带出处的经验材料。内容全部为原创虚构样本，没有抓取真实帖子。
- **面试准备**：选择项目和轮次，一问一答、深挖和弱点反馈，并引用本项目保存的 ES 与材料。
- **Calendar**：一键模拟连接、同步已确认日程、改期更新；可以下载真实的 ICS 文件，里面只有虚构日程。

研究收集、蒸馏内容与 Calendar 连接均为演示；没有连接真实网站、AI 模型或账户。ES 和回答只留在你的浏览器里，不会写进 GitHub 发布包。

## 怎么放到 GitHub

1. 建一个新仓库，例如 `shukatsu-os-showcase`。
2. 上传**这个项目文件夹里面的内容**，让 `index.html` 位于仓库根目录；保留 `src`、`assets` 等子文件夹。
3. 要展示网页，在仓库 **Settings → Pages → Deploy from a branch** 中，选择默认分支和 **/(root)**，保存。
4. GitHub 部署完成后，把 Pages 提供的网址作为作品集演示链接。

仓库本身的 README 会展示项目介绍、操作方法、设计选择和验证范围。网页部署方法已参照 [GitHub 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 展示时怎么解释

围绕三个问题讲：为什么按公司整理、如何区分事实和意向、怎样在新证据出现后更新下一步。参照 [演示讲解顺序](docs/demo-guide.md)。

本版本的分流和状态逻辑可以实际运行；邮件与抽取结果为预置样本，没有接入 AI 模型和真实账户。不要把样本测试结果写成真实用户效果，也不要声称所有代码都由个人独立编写。

## 完整用途

Shukatsu OS 将机会整理、七维企业与业界研究、过往 ES／选考经验整理、知识蒸馏、本人素材、ES 修改复查、面试准备、项目截止与日历、每日行动连在一起。检索会参考官网、IR 和可访问的 OpenWork、BizReach Campus、外资就活等经验资料；保留出处、年度、职种和轮次。

研究结果会变成志望动机切入点、ES 深挖问题和逆質問，再关联到具体公司的具体项目。完整工作流由私用台账与配套 agent skills 协作，公开网页展示虚构资料的流程；不代表网页已接通真实抓取或无人报名。
