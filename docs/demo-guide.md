# Two-to-three-minute walkthrough

The first visit starts with 12 processed fictional notices. Saved edits are preserved. Use the top-right reset control to return to an empty workspace; reload preserves that intentional empty state.

1. **Check evidence (30 seconds).** Open the notice from the guide or inbox. Distinguish a cancellation deadline from an application deadline.
2. **Prepare (one minute).** Open Preparation, choose Aster's ES, edit the draft and save a version. Company research and interview practice are grouped here too.
3. **Review a schedule change (one minute).** Open Calendar, connect the simulation, then apply Aster's reschedule. Two confirmed events remain two; the conflict clears.

The main navigation contains Overview, Inbox, Companies / Projects, Preparation and Calendar. Other functional views live under **その他**. The tool update, collaboration design and limitations are documented in the GitHub README.

The overview contains the consolidated scope notice. PDF and ICS downloads are real files containing fictional data. There are no external account connections or submissions.
