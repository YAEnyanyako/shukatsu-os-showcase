# Shukatsu OS：機能とワークフロー全体

**機会の発見、企業研究、ESの改善、面接準備、次の行動までをつなぐAI支援の就活ワークスペース。** 会社 → プロジェクトを軸に、同じ会社のインターンと本選考でも締切・メール・草稿・準備を分けます。

## 一連の流れ

機会を見つける → 会社と募集を特定する → 事業と選考を調べる → 資料から準備の要点を抽出する → 本人の確認済み経験と結びつける → ESを改善する → 面接を準備する → 締切と次の行動を管理する。

## 機能と成果物

| 領域 | ワークフローで行うこと | 公開デモで確認できること |
|---|---|---|
| メール・機会整理 | 会社と通知種別の2軸で分類し、招待・予約確認・選考課題・複数社のまとめを区別 | 架空の構造化通知の分類、根拠表示、次の行動 |
| 会社・プロジェクト管理 | 同じ会社の異なる募集を分離し、締切・メール・ES・準備を紐づけ | 架空の4社・7プロジェクト、独立した資料と締切 |
| 企業・業界研究 | 採用ページ、公式サイト、IR、閲覧可能な経験談をAI支援で検索・整理。競合比較、志望動機の切り口、逆質問を作る | 7観点の研究サンプルと業界比較 |
| 過去ES・選考経験 | 閲覧可能または提供されたES例、面接体験談、質問・深掘り、ケース・GD・ワークショップの形式を取り込む。出典・年度・職種・段階を保持 | OpenWork、BizReach Campus、外資就活、ONE CAREER等の出所区分を持つ架空の素材 |
| 知識の蒸留 | 評価観点、質問の傾向、準備上の教訓を抽出し、根拠と不明点を残す | 重複収集を防ぐサンプル収集と、出典付き素材棚 |
| 本人の経験素材 | 確認済みの経験・事実を参照して回答を準備し、他者の体験と区別する | 架空の本人素材と参考体験談を分離 |
| ES添削・改善 | 設問、草稿、企業研究、本人素材をもとに具体性・深掘りリスク・表現を診断。修正後に文字数と論理を再確認。明示的な依頼があれば書き換えを支援 | 募集別の草稿編集、文字数、版保存、事前作成の診断ガイド |
| 面接準備 | 企業・職種・段階、提出ES、研究、蒸留素材から想定質問、回答骨子、逆質問、弱点を整理。別の模擬面接フローで深掘り練習 | 段階別のサンプル質問・回答・深掘り、保存ESと素材を参照する準備パック |
| 締切・Calendar | 提出・回答期限、開催日時、取消期限を区別し、確定予定の重複と変更を扱う | 接続・同期のシミュレーションと、架空予定のICS出力 |
| 日々の行動と継続 | 本人が報告した活動と次の一手を記録。確認時刻と出典IDを残し、次回は新規項目を中心に処理 | ローカルのタスク状態、実行根拠、重複を防ぐ再実行。本人が入力した非空の返答で保存する架空の日誌も表示 |
| サイトのイベント・スカウト | 閲覧可能な個別通知の職種との適合性と次の対応を確認。企業名不明は未確認のまま扱う | 会社不明スカウトと会社・募集の整理。サイト上の無人応募・予約は本公開版の対象外 |

## 企業研究の7観点

1. 基本面：規模、業績、事業構成、業界での位置。
2. 戦略：中期方針、投資、課題。
3. 部門・職種：実務、必要能力、キャリア。
4. 事業・収益：商品、顧客、収益の仕組み。
5. 競合：2〜3社を同じ基準で比較。
6. 文化・人：公式の人物像と、出典を明記した社員の経験。
7. 動向：日付のあるニュースを志望動機や逆質問につなげる。

成果物は、その会社固有の志望理由、職種理解、実務に踏み込んだ逆質問です。

## 資料をES改善につなぐ例

閲覧できる過去の面接体験談を、年度・職種・段階・出典とともに保存します。そこから評価観点を抽出し、準備すべき問いに変えます。その問いを本人の確認済み経験と草稿に照らし、具体的な行動の不足、因果の飛躍、追問される箇所を指摘します。本人が修正し、次の確認で問題の解消と文字数を確かめます。

企業研究、根拠、文章の改善をつなぐことが、この仕組みの中心的な設計判断です。参考資料を増やすだけでなく、次の準備に使える形へ変換します。

## 動作環境と公開範囲

実際の作業環境では、私用台帳・ローカルツールと、研究、素材取り込み・蒸留、ES添削、面接準備のエージェントスキルを組み合わせます。スキル定義とローカルの企業・面接レポートからフローの設計を確認できますが、すべてのサイトで無人実行が完了しているという意味ではありません。これらの補助スキルと私用資料は、この単体リポジトリには同梱していません。

利用できる閲覧ツールとともに起動すると、エージェントが検索・整理を支援します。OpenWork等のログイン制限がある資料は、許可された閲覧または提供されたテキスト・画像から取り込みます。サイト全体の無人クローラーではなく、読めない情報は不足として残します。過去の体験談は年度付きの事例として扱います。

公開サイトは架空データで情報構造を示します。ローカル編集、ルール処理、保存、ICS出力は動作します。実Web収集、LLMによるES添削、外部メール・カレンダー接続は補助環境が必要で、この公開サイトには接続していません。

## v2.1で増えた操作

資料・版では企業研究、ES、面接準備、応募記録を用途で表示。確認版の優先、保存日時と状態、他の版の折り畳み、架空CVのPDF生成が動きます。面接準備は明示的な案内や書類通過例に応じて開き、AI面接の書類選考段階は維持します。未完了確認では保存中の招待や旧・無期限事項も対象にし、受領通知は該当の一歩だけを更新。日誌は本人の明示的な入力だけから保存します。

[操作ガイド](demo-guide.md)で順に体験できます。すべて架空の通知・資料を使う手動デモで、実メール・夜間自動実行は接続していません。
